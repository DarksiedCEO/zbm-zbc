### Equivalent (proof by reading plus probe)
- N026 `isdecimal()` for `"0" <= ch <= "9"` in number_cluster_spans: every input reaches it after `screen_form`/`_norm`, and `strip_format` rewrites every Nd character above U+007F to its ASCII digit; probe: of the 798 non-ASCII `isdigit` characters, 69 survive `screen_form` unchanged and none is `isdecimal` (`probes/probe_cluster.py`). So `isdecimal` is true only for ASCII digits there.
- F007 `st_size > len(mem)` for `!=`: a smaller file makes `_pread_exact(fd, len(mem), 0)` return fewer bytes, which differs from `mem`, so the result is the same "differs"; probe on an empty log (regular, FIFO, directory, larger regular file) gives identical results to pristine.
