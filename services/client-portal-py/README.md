# client-portal-py — the client acceptance page (ADR 0028)

The one place a client accepts Z Best Media's documents. Andre creates an acceptance link at Legal for one client and
exact document versions (the MSA and a SOW); the client opens it here, reads the full text of each document, ticks one
unticked box per document, types their name, title and company, and selects **Accept and sign**. Legal records one
acceptance per document; Finance's contract gate (FIN-29) then counts it. Andre's steps:
`docs/runbooks/client-acceptance.md`. Design and threat model: `docs/adr/0028-client-acceptance-page.md`.

The service is stateless and holds no record: every acceptance, link and piece of evidence is Legal's. The page's
words are rendered by Legal (the founder-approved clickwrap text v1, Parts B and C, as blocks; AEGIS M-5) and laid out
here; Legal checks the page text at submission. Part D (the confirmation email) is built here.

## Run

```bash
cd services/client-portal-py && python3 -m pytest -q   # test counts: docs/test-counts.md (generated by CI)
export PORTAL_LEGAL_URL=http://127.0.0.1:8420           # Legal's base URL (plain http only to *.railway.internal or localhost)
export PORTAL_LEGAL_SERVICE_TOKEN=<Legal's service token>
export PORTAL_LEGAL_CALLER_TOKEN=<Legal's client_portal caller token>
export PORTAL_EVIDENCE_KEY=<32+ random printable characters>
export PORTAL_PUBLIC_ORIGIN=http://127.0.0.1:8480       # the page's own origin (https://... in production)
cd src && python3 -m api                                # PORTAL_BIND_ADDR (127.0.0.1), PORTAL_PORT (8480)
```

| Setting | Default | Notes |
|---|---|---|
| `PORTAL_LEGAL_URL` | required | Legal's base URL; on Railway `http://legal.railway.internal:8420` |
| `PORTAL_LEGAL_SERVICE_TOKEN` | required | Legal's service token (bearer) |
| `PORTAL_LEGAL_CALLER_TOKEN` | required | this service's `client_portal` caller token at Legal: it reaches only Legal's three `/legal/v1/portal/...` routes (`invitations/resolve`, `receipts`, `acceptances`) |
| `PORTAL_LINK_TAG_KEY` | required | Legal's `LEGAL_LINK_TAG_KEY` (a Railway reference): a link token whose tag does not verify is the 404, refused before any budget is spent or Legal is asked (AEGIS r2 N-M1; `src/link_tag.py` is byte-identical to legal-py's) |
| `PORTAL_EVIDENCE_KEY` | required | >= 32 printable characters. HMAC key for the client's IP address and user agent (recorded at Legal as HMACs only), the form signature and the retry key. Rotating it invalidates open forms (the client reloads) and changes `hmac_key_id` on later acceptances; keep the old value offline to verify old HMACs |
| `PORTAL_PUBLIC_ORIGIN` | required | the exact origin the page is served from (`https://<domain>`); a POST whose `Origin` differs is refused |
| `PORTAL_CLIENT_IP_HEADER` | `x-real-ip` | the header Railway's edge sets to the client address (**UNVERIFIED**: a moderator's statement, not a documented contract; runbook step 8); `none` = do not read one |
| `PORTAL_TRUSTED_PROXY_HOPS` | 1 | 0..3: fallback when that header is missing: the `X-Forwarded-For` entry this many from the END (never the left-most); 0 = the socket peer |
| `PORTAL_RATE_LEGAL_PER_MINUTE` | 300 | every call to Legal, all clients together, charged before the call (AEGIS M-3) |
| `PORTAL_RATE_IP_PER_MINUTE` | 30 | requests per client address per minute on `/accept/...` |
| `PORTAL_RATE_TOKEN_PER_HOUR` | 40 | requests per link per hour, charged before any Legal call (only tag-valid links are counted; at the limit the log names the link by its 8-hex log fingerprint, AEGIS r3 N3-M1). Only a link Legal answered a FINAL 404 for (`"final": true`: unknown, used, expired, revoked) is not asked about again for 15 minutes; any other 404 and every 503 are asked again (AEGIS r4 N4-L2). Only the one spelling of a token Legal minted is accepted (N4-L1) |
| `PORTAL_RATE_NOT_FOUND_PER_MINUTE` | 120 | not-found answers per minute, all clients together |
| `PORTAL_FORM_MAX_AGE_SECONDS` | 14400 | how long a served form can be submitted (300..86400) |
| `PORTAL_LEGAL_TIMEOUT_SECONDS` | 5 | 1..30 |
| `PORTAL_DISPLAY_TZ` | `America/Los_Angeles` | the time zone of dates on the page and the confirmation (clickwrap text: Pacific Time) |
| `PORTAL_BIND_ADDR`, `PORTAL_PORT` | `127.0.0.1`, 8480 | the Docker entrypoint maps Railway's `PORT` onto `PORTAL_PORT` |

## Routes

| Route | Answer |
|---|---|
| `GET /health` | `{"status":"ok"}` and nothing else (AEGIS r4 N4-L3). The link format version and the tag key's id (8 hex characters of its SHA-256, never the key) are logged at startup (`link tags: format version 1, key id <8 hex>`), to match against Legal's private `/health` `link_tags` |
| `GET /accept/{token}` | the page for this link (Part B: MSA + SOW; Part C: a new SOW for a client with a counted MSA acceptance) |
| `POST /accept/{token}` | records the acceptance at Legal; the confirmation page |
| `GET /accept/{token}/document/{1,2}` and `/download` | the document's exact registered text (its SHA-256 is the fingerprint on the page) |
| `GET /accept/not-now`, `GET /robots.txt` | static |

Every unusable link (malformed, unknown, expired, revoked, used, a document changed, a page the service does not
serve) gets the same 404 page.

## Security properties

- **Public, stateless, no cookies, no script.** Server-rendered HTML; CSP `default-src 'none'` with the one inline
  stylesheet allowed by hash; `form-action 'self'`, `frame-ancestors 'none'`, `base-uri 'none'`; `no-store`;
  `Referrer-Policy: same-origin` (the token in the path never leaves in a Referer, and the browser still sends
  `Origin` on the POST); nosniff; HSTS; noindex; no `Server` header.
- **The token.** 256 bits from Legal, single use, at most 14 days, revocable by Andre; Legal stores only its SHA-256
  and compares in constant time. The token goes to Legal in a JSON body, never in a URL Legal could log. The format is
  checked here first; a malformed token never reaches Legal.
- **CSRF.** The POST needs the form this service served for this link (HMAC over the token's hash, the page text's
  hash and the issue time; at most `PORTAL_FORM_MAX_AGE_SECONDS` old) and an `Origin` equal to `PORTAL_PUBLIC_ORIGIN`;
  `Sec-Fetch-Site`, when sent, must be `same-origin`. `application/x-www-form-urlencoded` only.
- **Limits.** Request target 2 KiB, head 8 KiB, form body 8 KiB, 10 s body deadline; rate limits per client address,
  a global ceiling on Legal calls charged before each call, per confirmed link, and on not-found answers, keyed by
  HMACs (AEGIS M-3; the attacker cost is in ADR 0028); uvicorn: 64 concurrent connections, 5 s keep-alive, 16 KiB
  head.
- **What Legal receives.** The documents with their hashes, each box's own tick, the page text as shown and its hash,
  the typed name, title and company, and HMAC-SHA256 values of the client's IP address and user agent with the key's
  id. Never the IP address or the user agent themselves.
- **Exactly once, and a retry sees its confirmation.** Legal uses the link up in the same operation that records the
  acceptances. A refresh or a retry after a lost response (the same form) gets the confirmation from Legal's receipt
  for that submission's request id (AEGIS M-2); any other submission on a used link gets the 404.
- **Typed fields** are NFKC-normalized; bidi, zero-width, default-ignorable, blank-filler and other invisible or
  control characters are refused here and at Legal, with the same rule (AEGIS L-1, r2 N-L3); the company match is
  legal-py's normalization on both sides (r2 N-L1).
- **Junk costs nothing** (AEGIS r2 N-M1): a link token carries an HMAC tag under the key Legal mints with; a token
  without a valid tag is refused before the per-address limit, the Legal-call ceiling or the not-found ceiling is
  charged. IPv6 clients are counted per /64. The receipt lookup carries the hash of the form signature this page
  issued (r2 N-L4); the confirmation's time-zone label is Legal's zone's (r2 N-L5).
- **Nothing logged** but the route name, the status and the time taken: never a token, a name, an email, an IP
  address or a user agent. uvicorn's access log is off.
- **Accessible.** Every field and box has a label; errors are listed in an alert summary linking to each field, and
  each field says its error (`aria-invalid`, `aria-describedby`); boxes come back unticked; keyboard only, visible
  focus, light and dark colour schemes with WCAG AA contrast; no timeouts on the page itself.

## Mail

No mail provider is wired (`src/mail.py`, `NotWiredMailer`). The confirmation page then says Z Best Media will email
the copy, and Andre sends the clickwrap Part D email by hand (runbook step 5). A real adapter implements
`ConfirmationMailer` and is passed to `create_app` with ZBM's postal line and the next-step sentence; it must use the
invitation id as the provider's idempotency key.

  wrong client, tampered hash, template changed after the invitation).
